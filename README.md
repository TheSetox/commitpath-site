# CommitPath website

This repository serves CommitPath's public Home, Support, and Privacy pages through GitHub Pages. The site is plain HTML and CSS; it does not need a build step or JavaScript.

- Website: https://thesetox.github.io/commitpath-site/
- Support: https://thesetox.github.io/commitpath-site/support/
- Privacy: https://thesetox.github.io/commitpath-site/privacy/
- Contact: developer@siapknow.com

To preview locally, run `python3 -m http.server 8765` from this directory and open `http://127.0.0.1:8765/`.

The privacy policy describes the free, account-free CommitPath 1.0 release for Android, iOS, and macOS. Review it, each signed store build's linked SDK behavior, and store data disclosures before submitting the app for public distribution or enabling production advertising. A future custom domain should serve the AdMob `app-ads.txt` file at its root; a GitHub Pages project path alone does not satisfy that requirement.
